## Documentation rule

When behavior, a resource URL, a release procedure, or a storage key changes, update the matching guide in the same Git commit. Documentation should describe the checked-in project, not an older version of it.

Do not place real account information, passwords, browser storage exports, access tokens, or private family information in these guides.
