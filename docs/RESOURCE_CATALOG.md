## Owner review checklist

For each resource release review:

- [ ] The destination resolves or visibly loads in a normal browser.
- [ ] The linked page still describes the named program or service.
- [ ] The description in Mommy's List does not promise eligibility or availability.
- [ ] The link uses HTTPS where the provider supports it.
- [ ] The card still belongs in its current category.
- [ ] The title is understandable without agency jargon.
- [ ] The destination opens in a new tab with `noopener noreferrer` protection.
- [ ] Counts in the website, this catalog, and the verification script agree.
